# 🃏 好友德州扑克 (Friends Texas Hold'em)

一个跟好友一起玩的在线德州扑克。**无需注册登录**，建一个房间号发给好友，打开链接就能一起玩。带实时聊天。

- 2–6 人同桌，起始筹码 10000，盲注 50/100
- 完整德州扑克规则：盲注、翻牌前/翻牌/转牌/河牌四轮下注、比牌、**边池 (all-in side pot) 结算**
- 刷新/断线可自动重连回原座位
- 手机、电脑浏览器都能玩
- 语音功能预留在架构里（第二阶段接入 WebRTC）

## 本地运行

```bash
npm install
npm start
```

然后浏览器打开 http://localhost:3000 。想在同一台电脑上测试多人，可以多开几个浏览器标签或用无痕窗口，各自输入同一个房间号。

同一局域网（比如都连同一个 Wi-Fi）的好友，也可以用你电脑的内网 IP 访问，例如 `http://192.168.1.20:3000`。

## 让不在身边的好友一起玩：免费部署到云端

要让不同网络的好友都能连进来，需要把它部署到一个公网服务器。下面两个平台都免费、支持 WebSocket，几分钟搞定。

### 方案 A：Render（推荐，最简单）

1. 把这个文件夹推到一个 GitHub 仓库。
2. 打开 https://render.com ，用 GitHub 登录。
3. New → **Web Service**，选中这个仓库。
4. 配置：
   - **Build Command**: `npm install`
   - **Start Command**: `npm start`
   - Instance Type 选 **Free**
5. 点 Create。等它部署完，会给你一个网址，如 `https://your-poker.onrender.com`。
6. 把这个网址发给好友即可。

> 说明：端口由平台通过环境变量 `PORT` 提供，代码已自动读取，无需改动。免费实例闲置会休眠，第一次打开可能要等十几秒唤醒。

### 方案 B：Railway

1. 打开 https://railway.app ，用 GitHub 登录。
2. New Project → Deploy from GitHub repo，选中仓库。
3. Railway 会自动识别 Node 项目并运行 `npm start`。
4. 在 Settings → Networking 里点 **Generate Domain** 得到公网网址。
5. 发给好友。

## 怎么玩

1. 每个人打开网址，输入昵称和**同一个房间号**（第一个人可以点“随机”生成一个，再用“复制邀请链接”发给大家）。
2. 人齐了（≥2 人），任意一人点“开始下一局”发牌。
3. 轮到你时，底部会出现操作按钮：弃牌 / 看牌 / 跟注 / 加注（拖动滑块选额度）/ 全下。
4. 一局结束后点“开始下一局”继续。谁筹码输光了，就要等这局打完；点“重置筹码·重开对局”，**全体玩家都同意**后，所有人筹码重置为 10000、开启新一轮（这样才公平——赢的人也得同意才会清零重来）。

## 行动倒计时（防挂机）

轮到谁行动，谁的座位上会显示倒计时（默认 **30 秒**）。到时没操作会自动处理：有人下注就自动弃牌，没人下注就自动看牌，牌局继续，不会被挂机的人卡住。计时在服务器端判定，关掉页面也照样走。

想改时长：在 Render 的 Environment 里加变量 `TURN_SECONDS`（最小 10），比如 `TURN_SECONDS=45`；本地运行则 `TURN_SECONDS=45 npm start`。

## 自定义

想改盲注、起始筹码、人数上限，在 `server.js` 里创建 `Table` 的地方改：

```js
new Table({ maxSeats: 6, smallBlind: 50, bigBlind: 100, startingStack: 10000 })
```

## 机器人 AI 算法

机器人不依赖任何外部服务，决策在服务器端实时完成。设计借鉴了 CFR/GTO 类扑克 AI（如 Pluribus/DeepStack）的**核心决策原则**，用轻量方式实现：

- **蒙特卡洛胜率（equity）**：每次轮到机器人，实时模拟数百次随机发牌（随机补齐公共牌 + 随机对手底牌），算出当前对全部在场对手的真实获胜/平局概率。校验结果贴合扑克已知值（AA 对单人 ≈0.85，AKs ≈0.67，最差的 72o ≈0.35）。
- **底池赔率 EV 决策**：核心规则是「胜率 ≥ 底池赔率才跟注」——这正是博弈论最优（GTO）的地基。
- **混合策略与平衡**：价值加注、半诈唬、纯诈唬按频率随机触发，并混用多种下注尺度（半池 / 2⁄3 池 / 满池），让机器人不可预测、更难被针对，而不是每次都用同一套动作。
- 翻牌前对“对手是完全随机牌”的乐观估计做收紧修正，避免用弱牌乱打。

> 注：那种完整的 CFR + 神经网络蓝图 + 在线重解系统（需要 C++/GPU 训练、Redis/IPC 等基础设施）只适合单挑研究场景，无法塞进这个轻量服务器；这里采用的是同源的决策思想的实用实现。想让机器人更凶/更稳，可在 `src/bot.js` 里调整各频率与阈值。


## 在线语音

房间内自带实时语音，基于 **WebRTC 点对点（P2P mesh）**：开麦的人两两直接传音频，服务器只转发连接握手信令、不经手音频流，延迟低、也省服务器带宽。

- 右上角麦克风按钮：点一下开麦（浏览器会请求麦克风权限，首次需允许），再点关闭。
- 开麦的玩家座位上会显示 🎤；正在说话的人座位会绿色高亮。
- 已启用回声消除 / 降噪 / 自动增益。

> 说明：使用了公共 STUN 服务器做 NAT 穿透，绝大多数家庭网络可直接连通。极少数对称型 NAT/严格防火墙下两人可能听不到彼此，那种情况需要额外的 TURN 中转服务器（免费方案有限）——如果遇到，告诉我再加。语音需要 HTTPS（Render 已是 https，本地 localhost 也可）。
